Как собрать экспертный Motion Reels с Claude Code

AI-маркетинг Инструменты Контент

Ролик, который вы посмотрели, собран ровно по этим шагам. Я написала сценарий, начитала голос на диктофон и объяснила задачу словами. Картинку собрал код.

Дизайнера нет. Монтажёра нет. Видеоредактор я не открывала. На первый ролик ушёл час. Дальше меньше, потому что правила уже написаны и работают на все следующие ролики.

Из программирования не нужно ничего. Нужно уметь объяснять задачу словами и говорить, что вам не нравится. Вот честно, это весь список навыков.

Как пользоваться инструкцией. Идите по шагам сверху вниз. Тёмные блоки копируются кнопкой целиком. В конце статьи лежит комплект файлов: правила, скрипты, настройки. С ним первые четыре шага занимают пять минут.

Что получится

Вертикальный ролик 1080×1920 с вашей озвучкой, субтитрами и анимацией. Интерфейсы, схемы и графики рисуются кодом, поэтому любую правку вы вносите словами и получаете новую версию за минуту.

Плагины и расширения ставить не нужно. Роль навыков здесь выполняют обычные текстовые файлы с правилами, которые Claude читает в начале каждой сессии. Про них шаг 4.

1Поставить Claude Code

Два пути, оба рабочие.

Путь А, без терминала. Скачать десктоп-приложение Claude и включить в нём Claude Code. Подходит, если командная строка пугает. Так работала я.

Путь Б, через терминал. Открыть Терминал и выполнить:

Команда · установка
npm install -g @anthropic-ai/claude-code

Потом запускать командой claude из папки проекта. Актуальные ссылки: claude.com/code и docs.claude.com. Команда установки иногда меняется, в документации она всегда свежая.

2Поставить Node.js

Открыть nodejs.org, скачать версию с пометкой LTS для своей системы. На Mac это файл .pkg, запускается двойным кликом и просит пароль от компьютера. Проверка, что встало:

Команда · проверка
node -v

Должна появиться версия вида v22.x.x или выше. Если терминал отвечает command not found, установка не прошла. Node нужен потому, что на нём работает Remotion. Сам по себе он ничего не делает и в фоне не висит.

3Сделать папку проекта

Важный момент, на котором я потеряла несколько часов. Не кладите проект на Рабочий стол и в Документы. Эти папки синхронизируются с iCloud. Он выгружает содержимое в облако и оставляет пустые заглушки: размер у файла есть, а данных на диске нет. Программа пытается прочитать файл, не может и зависает без единой ошибки. У меня из-за этого дважды опустела папка с библиотеками и один раз исчезла запись голоса.

Правильно: создать папку в домашней директории.

Команды · папка проекта
mkdir ~/reels-factory
cd ~/reels-factory
mkdir resources scripts public out src

Если хочется иметь папку под рукой на Рабочем столе, сделайте ярлык:

Команда · ярлык
ln -s ~/reels-factory ~/Desktop/reels-factory
ПапкаЧто лежит
resourcesправила: стиль, сцены, версии
scriptsсценарии роликов и служебные скрипты
publicозвучки
outготовые видео
srcкод сцен, его пишет Claude

4Положить файлы правил

Это главное. Без правил Claude каждый раз придумывает стиль заново, и ролики не похожи друг на друга.

В корень проекта кладётся файл CLAUDE.md. Его Claude читает первым в каждой сессии: что за проект, где что лежит, как с вами разговаривать, что запрещено. В папку resources кладутся правила по темам:

ФайлО чём
style.mdцвета с кодами, шрифты, размеры, безопасные зоны
scene-rules.mdкак переводить смысл в картинку
reels-skeleton.mdструктура сценария: хук, приёмы, обещание, кодовое слово
versioning.mdправки только новыми версиями, оригинал не трогается
production-guide.mdполный свод: удержание, звук, минимальное время чтения

Готовые шаблоны этих файлов лежат в комплекте в конце статьи. Свои цвета и шрифты вы подставите за пять минут.

Самое важное правило, скопируйте его целиком: переводить смысл в визуал, не иллюстрировать слова буквально. Перед каждым абзацем задавайте вопрос: какая картинка передаст смысл фразы человеку без слов? Фраза «алгоритм не успевает обучиться» это не робот с книжкой. Это полоса обучения, которая замирает на четырнадцати процентах.

5Поставить Remotion

Запустить Claude Code в папке проекта и написать ему:

Промпт · установка
Прочитай все файлы в папке resources и запомни правила.
Установи Remotion в этот проект.

Он поставит всё сам. Если хочется сделать руками:

Команды · вручную
npm init -y
npm install remotion @remotion/cli @remotion/google-fonts react react-dom
npm install -D ffmpeg-static typescript

Пакет ffmpeg-static кладёт ffmpeg внутрь проекта. Отдельно в систему ставить его не нужно, Homebrew тоже не нужен.

6Записать голос

Пишите на диктофон телефона, одним дублем. Говорите спокойно, паузы между блоками делайте свободно, они подрежутся автоматически. Сбиваться и говорить своими словами можно: сборка идёт от расшифровки записи, а не от текста сценария. Пишите в тихой комнате, шум потом не убрать.

Готовый файл положить в папку public. Формат любой: ogg, m4a, wav.

Слова «первое», «второе», «третье» станут границами сцен

7Разложить запись по сценам

Здесь происходит то, что обычно делает монтажёр.

Расшифровка. Запись распознаётся на вашем компьютере, без отправки в интернет. Модель скачивается один раз.

Команды · расшифровка
npm install @huggingface/transformers
node scripts/transcribe.mjs public/voice.mp3

На выходе список слов с точным временем каждого.

Подрезка пауз и границы сцен.

Команда · сборка дорожки
node scripts/tighten-audio.mjs

Скрипт делает четыре вещи: режет паузы между словами до одной десятой секунды, слегка ускоряет речь без изменения высоты голоса, выравнивает громкость до стандарта соцсетей и считает границы сцен по словам-маркерам «первое», «второе», «третье». Мой ролик после этого стал короче на девять секунд и заметно живее. Оба скрипта лежат в комплекте.

Почему границы считаются по словам. Я пробовала делить по длине текста и по длине пауз. Оба способа дают рассинхрон: картинка про одно, голос про другое. По словам-маркерам попадание точное.

8Собрать сцены

Дальше вы разговариваете с Claude обычными словами:

Промпт · сборка
Открой scripts/01-name.md и собери сцены 1-3.
Покажи предпросмотр в Remotion Studio.

Сцены лучше собирать партиями по три. После каждой партии смотреть и править. Если попросить сразу шесть, правок будет столько же, но искать их придётся дольше.

Что важно проговорить один раз и записать в правила: одна сцена равна одному блоку текста и одной мысли; одна анимация-акцент на сцену, иначе кадр рассыпается; смысловой бит каждые две-четыре секунды; на нулевом кадре уже стоит читаемый смысл, потому что первый кадр это обложка в ленте.

Команда · предпросмотр
npm run studio

9Править скриншотами

Самая недооценённая часть. Делаете скриншот кадра, обводите место, которое не нравится, кидаете в чат и пишете словами, что не так. «Тут цифра мелкая», «этот блок должен появляться позже», «фон слишком пустой».

Правило, которое стоит записать в versioning.md: любая правка создаёт новую версию сцены, оригинал остаётся. Тогда в предпросмотре обе версии видны рядом и можно сравнить. Это спасает, когда первый вариант оказался лучше второго.

Оригинал не трогается. Не понравилась правка, вернулись назад.

10Отрендерить

Команда npm run studio и кнопка Render в интерфейсе. Либо напрямую:

Команда · рендер
npx remotion render Reel01Full out/reel.mp4

Готовый файл 1080×1920 лежит в папке out, его можно сразу загружать в соцсеть.

Грабли, на которых теряется вечер

iCloud. Про это было в шаге 3. Если проект уже лежит на Рабочем столе и всё начало зависать без ошибок, перенесите папку в домашнюю директорию.

Команда npx подвисает. На некоторых машинах она проверяет реестр пакетов и висит. Запускайте через npm run или напрямую из папки: ./node_modules/.bin/remotion.

Не хватает памяти. Если открыто много вкладок браузера, система убивает процессы рендера, и команда виснет молча. Закройте лишнее и рендерите с ключом --concurrency=1.

Две сессии в одной папке. Не запускайте два окна Claude Code в одном проекте. Они затирают файлы друг друга. У меня так стёрлась запись голоса и половина библиотек.

Нет истории версий. Поставьте git с самого начала, тогда любую потерю можно откатить одной командой.

Комплект файлов

Всё, что описано выше, собрано в один архив:

  • шаблоны правил: CLAUDE.md и шесть файлов resources с местами под вашу палитру и шрифты;
  • рабочие скрипты: расшифровка, подрезка пауз, выравнивание громкости, интерфейсные звуки;
  • готовый package.json со всеми зависимостями;
  • полный свод правил производства и чек-лист из пятнадцати пунктов перед публикацией.

Комплект обезличен: цвета и шрифты помечены как места для ваших значений.

Если что-то непонятно

Застряли на каком-то шаге, это нормально. И тут приём, который важнее самой инструкции. Скопируйте текст этой страницы целиком, вставьте в свой Claude и напишите:

Промпт · разбор инструкции
У меня есть инструкция, текст ниже. Я застряла на шаге [номер].
Вот что у меня происходит: [опиши своими словами, что видишь на экране].
Разбери этот шаг подробнее, веди меня по одному действию за раз
и жди моего подтверждения после каждого. Покажи, где я что-то упускаю.

[сюда вставь текст инструкции]

Нейросеть разберёт инструкцию под вашу ситуацию и поведёт по шагам. Освойте этот приём один раз, и слово «непонятно» перестанет вас останавливать где-либо вообще. А если всё равно не выходит, напишите мне в директ, контакты ниже.

Стена, которой больше нет

Заметьте, что сейчас произошло. Человек без технического образования собрал то, за что год назад платят трём подрядчикам. Нейросеть сделала руки. Голова осталась ваша: сценарий, смысл, понимание, для кого это.

Это касается далеко не только роликов. Таргетолог, специалист по настройке рекламы в Instagram*, работает удалённо, из дома или из любой точки, клиенты по всему миру. Раньше в эту профессию не пускал рекламный кабинет: кнопки, настройки, чужие деньги, страшно нажать. Сейчас связка та же, что с роликом. Нейросеть делает руки, вы ставите задачу и принимаете решения.

По анкетам моих учениц самая частая фраза звучит так: «с теорией знакома, а практиковаться страшно». Человек проходит курс, смотрит уроки и выходит теоретиком. Знания есть, уверенности нет, клиентов брать боязно. Знакомо?

Поэтому я собрала продукт, где уроков смотреть не надо.
